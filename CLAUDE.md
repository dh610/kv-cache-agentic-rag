# Shared project entry point

Read AGENTS.md, README.md, docs/onboarding.md, docs/team-contract.md and docs/contracts.md before modifying this repository.
Follow AGENTS.md's branch rules: inspect the working tree, work on a personal task branch, preserve others' changes, and submit a PR to main. Never edit, commit or push directly on main; merge only when authorized by the user.
Use the named role/file boundaries in docs/team-contract.md. Domain, synthesis and report remain unassigned; do not assume another member owns them.
Use the current GitHub implementation, not the earlier starter ZIP's file layout.
Role prompts live in prompts/<node>/*.j2, rubrics in rubrics/<node>.yaml,
and reproducible cases in tests/fixtures/<node>.
The common runtime owns question iteration, evidence merging, verification and status.
The final design's remaining differences are tracked in docs/final-design-review.md.
Do not treat mock output or an unmeasured retrieval score as a completed project result.
