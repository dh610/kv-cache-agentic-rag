# Report font

`NanumGothic-Regular.ttf` is bundled unchanged from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/nanumgothic) under the SIL Open Font License in `OFL.txt`.

The PDF renderer embeds subsets of this font so Korean text displays without requiring viewer-specific CJK fonts. Keep the license alongside the font when distributing the repository.
